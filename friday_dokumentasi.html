01 GAMBARAN UMUM
APA ITU FRIDAY?

FRIDAY (Framework for Intelligent Response and Decision Automation for You) adalah AI personal assistant berbasis Python yang berjalan di Termux pada Android. Terinspirasi dari asisten JARVIS/FRIDAY milik Tony Stark di film Iron Man, FRIDAY dirancang untuk menjadi partner kerja cerdas yang dapat diajak bicara, mengontrol aplikasi, mencari informasi real-time, dan merespons dengan suara.

Friday berjalan sepenuhnya di perangkat Xiaomi Pad 7 tanpa memerlukan komputer tambahan, menggabungkan kecerdasan Google Gemini 2.5 Flash dengan kemampuan lokal melalui Ollama sebagai fallback saat offline.

03 DETAIL SETIAP MODUL
modules/gemini_ai.py — AI UTAMA (GEMINI 2.5 FLASH)

Wrapper untuk Google Gemini API. Mendukung dua SDK: google-generativeai (legacy) dan google-genai (baru). Otomatis mendeteksi SDK yang terinstall.

Method utama:
  • tanya(perintah) — Tanya Gemini, return string
  • tanya_stream(perintah) — Generator, yield teks per chunk (streaming)
  • tanya_riset(perintah) — Tanya dengan token limit lebih besar (1200 token)
  • tanya_dengan_web(q, ctx) — Tanya dengan konteks web
  • bangun_konteks(...) — Gabungkan input user + waktu + cuaca + berita
  • reset_sesi() — Hapus history percakapan
Fitur:
  • Fallback: Gemini 2.5 Flash → 1.5 Flash otomatis
  • History percakapan (maks 20 pesan)
  • Streaming response word-by-word
  • Integrasi memori SQLite ke system prompt
  • Max token: 600 (chat) / 1200 (riset)
  • Temperature: 0.75, top_p: 0.95
modules/lokal_ai.py — AI OFFLINE (OLLAMA)

Wrapper Ollama untuk mode offline. Interface identik dengan GeminiAI sehingga main.py dapat switch tanpa perubahan kode.

Cara kerja:
  • Saat startup, cek port Ollama via socket (port 11434)
  • Verifikasi model sudah di-pull via /api/tags
  • Jika internet mati, _pilih_ai() di main.py otomatis pakai Ollama
  • Streaming via NDJSON /api/chat?stream=true
Model yang direkomendasikan:
  • qwen2:1.5b — ~1GB, cepat, bahasa Indonesia baik
  • tinyllama — ~600MB, paling ringan
  • phi3:mini — ~2.3GB, lebih pintar

Install: pkg install ollama di Termux

modules/suara.py — TEXT-TO-SPEECH

Sistem TTS berlapis dengan fallback otomatis. Voice: en-GB-RyanNeural (British male, paling mirip JARVIS).

Anti-echo: _sedang_bicara (threading.Event) di-set sebelum audio diputar, di-clear setelah selesai. Modul pendengar & wake_word membaca flag ini untuk tidak mendengarkan suara Friday sendiri.

Barge-in: stop_bicara() dapat diinterrupt dari thread manapun. Mendukung double-clap untuk memotong jawaban Friday di tengah.

modules/tampilan.py — TERMINAL UI JARVIS-STYLE

Semua output visual di terminal menggunakan box-drawing characters dan Colorama untuk tampilan JARVIS. Versi 6.0 dengan animated spinner dan streaming bubble.

Dashboard HTML real-time yang dibuka di Chrome/browser. Menampilkan waktu, cuaca, berita terkini, dan status Friday. Diupdate otomatis via JSON yang ditulis ke file lokal.

  • Kartu berita: Klik "Buka →" untuk membuka artikel di browser

  • Tombol Stop: Muncul saat Friday berbicara, interruptible
  • Cuaca visual: Ikon kondisi + suhu + angin + kelembaban
  • Auto-refresh: Data diperbarui setiap 30 menit via PeriodicRefresh thread

05 SISTEM SKILL LOKAL
KONSEP SKILL SYSTEM

Terinspirasi dari OpenJarvis, Skill adalah modul Python independen yang dieksekusi sebelum Gemini. Ini membuat respons jauh lebih cepat untuk perintah umum (buka app, putar musik, hitung) karena tidak perlu round-trip ke API cloud.

SkillManager di skills/__init__.py memuat semua skill secara dinamis, mengurutkan berdasarkan prioritas, dan mencari skill yang cocok dengan input user menggunakan keyword matching.

Jika skill cocok dan tidak return None → jawaban skill dipakai, Gemini tidak dipanggil sama sekali. Jika semua skill return None → diteruskan ke Gemini.

skills/musik.py — KONTROL MUSIK

Mengontrol Spotify dan memutar musik lokal via mpv.

Kontrol Spotify (3 metode fallback):
  1. termux-media-player via MediaSession Android (terbaik)
  2. Spotify broadcast intent langsung
  3. input keyevent — PLAY:126, PAUSE:127, NEXT:87, PREV:88
Buka Spotify:
am start -a android.intent.action.MAIN -c android.intent.category.LAUNCHER -p com.spotify.music

Musik lokal: Mencari file MP3/FLAC/M4A di /sdcard/Music dan memutar via mpv dengan shuffle playlist.

PERSONA FRIDAY — KEPRIBADIAN AI

System prompt mendefinisikan kepribadian Friday sebagai AI ala JARVIS:

  • Gaya bicara: Santai, natural, campuran Indonesia-Inggris ("On it", "Noted", "Stand by")
  • Panggilan: "Bos" atau "Bos Angga" — natural, tidak setiap kalimat
  • Humor: Kering ala JARVIS — singkat dan cerdas
  • Format: Maksimal 3 kalimat untuk pertanyaan biasa, lebih panjang hanya jika riset
  • Larangan: Tidak boleh markdown (**, #, backtick), tidak sebut sumber/URL
  • Wawasan: Teknologi, AI, gadget, politik global, ekonomi, film, musik, gaming
Contoh respons Friday: - "Sudah dieksekusi, Bos." - "On it. Kasih saya beberapa detik." - "Cuaca hari ini kurang bersahabat — saran saya bawa payung." - "Noted. Saya simpan di memori." - "Standby. Semua sistem hijau."

LANGKAH SETUP
  1. Clone repository: git clone https://github.com/Bomballed/friday-v4
  2. Masuk direktori: cd friday-v4
  3. Install dependencies: pip install -r requirements.txt
  4. Edit config.py — isi API keys Gemini, OpenWeatherMap, NewsAPI
  5. Set nama di NAMA_PENGGUNA = "NamaAnda"
  6. Jalankan Friday: python main.py

SETUP OLLAMA (MODE OFFLINE)
# Install Ollama via Termux package manager pkg install ollama # Jalankan Ollama server di background ollama serve & # Download model qwen2:1.5b (~1GB) ollama pull qwen2:1.5b # Friday otomatis switch ke Ollama saat internet mati

Internet check dilakukan setiap 20 detik via socket ke DNS Google (8.8.8.8:53). Jika gagal, Friday otomatis pakai Ollama. Jika Ollama juga tidak tersedia, Friday tetap menggunakan Gemini (mungkin gagal).

08 TROUBLESHOOTING & CATATAN TEKNIS
MASALAH UMUM DAN SOLUSI
MasalahPenyebabSolusi
mpv tidak memutar suara Android memerlukan audio output driver khusus Sudah diperbaiki: --ao=opensles ditambahkan ke flag mpv. Fallback ke --ao=android jika opensles tidak tersedia.
Streaming tidak terlihat, jawaban muncul sekaligus bicara() memanggil tampilkan_friday_bicara() yang print ulang setelah streaming selesai Sudah diperbaiki: flag _ss["sudah_tampil"] mencegah double display.
Spotify tidak play meski terminal menunjukkan "membuka" Syntax am start pkg salah; keyevent 85 adalah toggle bukan PLAY Sudah diperbaiki: syntax am start -a ... -p pkg yang benar; PLAY menggunakan keyevent 126.
Gemini error "thinking not supported" Versi SDK lama tidak mendukung thinking config Auto-reinisialisasi model tanpa thinking config.
Edge-TTS tidak bisa dijalankan Konflik asyncio event loop Edge-TTS dijalankan di thread terpisah dengan event loop baru.
"git restore config.py" error: path is unmerged File dalam status merge conflict Gunakan git checkout --ours config.py → git add → git stash drop.
CATATAN ANDROID/TERMUX
  • mpv di Android membutuhkan --ao=opensles untuk output audio
  • am start butuh syntax lengkap dengan -a, -c, -p
  • Termux:API harus terinstall untuk termux-media-player
  • Port audio (pyaudio) perlu portaudio: pkg install portaudio
  • IP Webcam: install di Android, start server, salin URL ke config
OPTIMASI PERFORMA
  • Internet check dicache 20 detik agar tidak delay tiap request
  • Berita dicache 30 menit via PeriodicRefresh thread
  • History Gemini dibatasi 20 pesan terakhir
  • History Ollama dibatasi 20 pesan, berita dibatasi 3 item
  • Skill berjalan lokal — 0ms latency, tidak butuh internet
  • Spinner animasi di thread terpisah — tidak block main loop
